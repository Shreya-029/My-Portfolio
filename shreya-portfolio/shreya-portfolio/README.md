# Shreya Sinha — Portfolio

A dark, cinematic one-page portfolio inspired by the uploaded portfolio video and populated from Shreya Sinha's resume.

## Files
- `index.html` — portfolio structure/content
- `style.css` — responsive visual design
- `script.js` — GSAP reveal/scroll animations and cursor effect

## Run locally
1. Keep all three files in the same folder.
2. Open `index.html` in a browser.
3. For the smoothest development experience, use VS Code + Live Server.

## Customize
- Replace project visual mockups with real project screenshots when available.
- Add the actual LinkedIn URL in `index.html` when you have it.
- Update project links once deployed.

The resume does not provide project URLs, LinkedIn URL, or project screenshots, so those have intentionally not been invented.
